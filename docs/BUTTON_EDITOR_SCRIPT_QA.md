# 按钮编辑器 · 动作脚本统一 — 手工验收清单

适用于 Native（`ui-native`）与 egui（`ui-egui`）按钮编辑器。每项在目标 UI 下各测一次即可。

## 前置

- [ ] 已授予**辅助功能**与**输入监控**（捕获点击 / 录制需要）
- [ ] 准备一个含 legacy 动作的配置备份（快捷键、打开应用、鼠标宏等旧类型）

## 1. Legacy 打开与显示

- [ ] 打开 legacy「快捷键」按钮 → 脚本区显示 `快捷键 …` 行，无动作类型下拉
- [ ] 打开 legacy「鼠标宏」按钮 → 步骤已转为 MeoFlow 文本；若有录制数据，`attached_macro` 仍可编译
- [ ] 打开 `Action::None` 按钮 → 脚本区显示默认骨架注释，非空白

## 2. 保存时 Lazy 升级

- [ ] 打开 legacy 按钮，不改脚本直接保存 → 配置中该按钮 `action` 变为 `script` 类型
- [ ] 打开 legacy 按钮，仅保留 `#` 注释后保存 → 变为 `none`（未配置）
- [ ] 保存后重新打开 → 不再提示「保存后将升级格式」

## 3. 快捷添加预设

| 预设 | 验收 |
|------|------|
| 快捷键 | wizard 录制 → 插入 `快捷键 Cmd+…` |
| 打开应用 | 选 .app 或点选窗口 → `打开应用 "…"` |
| 打开链接 | 输入 URL → `打开链接 "…"` |
| 打开文件 | 选文件 → `打开文件 "…"` |
| 粘贴文本 | 多行输入 → `粘贴 "…"` |
| 执行命令 | Shell 输入 → `执行命令 "…"` |
| 点击一次 | 捕获点击 → `点击 x y`（0~1 相对坐标） |
| 录制点击 | 开始录制 → 多次操作 → 完成 → 多行追加；`attached_macro` 保留 |

- [ ] 各预设 tooltip 与按钮标签可读
- [ ] 插入后状态栏步数 / 预览更新，无编译错误

## 4. 流程模板

- [ ] **输入后回车** / **粘贴后回车**：空脚本直接插入；已有内容时弹 Append / Replace
- [ ] **点击后快捷键**：点选坐标 → 录快捷键 → 三行模板
- [ ] **打开应用并输入**：选应用 → 输入文字 → 多行模板

## 5. 工具栏

- [ ] **捕获点击** / **捕获应用**：与快捷预设等效，Esc 可取消
- [ ] **试运行**：脚本可编译时执行；先聚焦目标窗口
- [ ] **语法说明**：打开 `docs/meoflow_cheatsheet.txt` 内容（Native 弹窗 / egui 窗口）

## 6. CLI 批量迁移（可选）

```bash
meotool --migrate-actions
# 或指定配置
meotool --config ~/path/config.toml --migrate-actions
```

- [ ] 输出 `migrated N button action(s)`；配置中 legacy 类型已变为 script
- [ ] 未配置按钮不受影响；编译失败的条目跳过并打 log

> 日常使用仅 **保存时 lazy 升级** 即可；CLI 用于一次性迁移整份配置。

## 7. 回归

- [ ] 外观 / 可见范围 / 图标编辑不受影响
- [ ] 面板点击按钮仍能执行已保存脚本
- [ ] `cargo test --features ui-native` 通过
- [ ] （若维护 egui）`cargo test --features ui-egui` 通过
